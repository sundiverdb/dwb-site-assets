Web-ready images and downloadable resources for startide.net, usablepatterns.net and becomingux.com.

This repo is public so WordPress can copy images from it. Only put images here
that are fine for anyone to see. No client data, no member data, no names other
than Dave's.

- One folder per site, then one folder per case study or page.
- Web-ready sizes only (about 1400px wide, JPG or WebP). Raw captures stay out.
- WordPress keeps its own copy of each image. The sites do not load from GitHub.
- Downloadable resources (PDFs) can go here too, in their own page folder.

## Free resources

- [Screen reader cheat sheets](usablepatterns/screen-reader-cheat-sheets/): accessible PDF quick references for JAWS, NVDA, Narrator, VoiceOver (Mac, iPhone and iPad) and TalkBack. Public domain (CC0).

Unless a folder has its own license, its files are not licensed for reuse.
